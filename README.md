# Smart Lender

Smart Lender is a Machine Learning based Loan Approval Prediction System developed using Flask.

## Technologies
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- XGBoost

## Machine Learning Models
- Decision Tree
- Random Forest
- KNN
- XGBoost

## Dataset
Loan Approval Dataset (Kaggle)

## How to Run

pip install -r requirements.txt

python train.py

python app.py
