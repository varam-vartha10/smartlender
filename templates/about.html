About Smart Lender

Smart Lender is a Machine Learning based Loan Approval Prediction System developed using Python, Flask and Scikit-Learn. The application predicts whether a loan application will be Approved or Rejected based on applicant information.


Project Objective

The objective of Smart Lender is to help banks and financial institutions evaluate loan applications quickly and accurately using Machine Learning, thereby reducing manual effort and improving decision-making.


Features

  • Loan Approval Prediction
  • Real-time Prediction using Flask
  • Machine Learning Based Decision Support
  • Fast and User Friendly Interface
  • Best Model Automatically Selected
