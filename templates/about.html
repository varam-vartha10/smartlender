About Smart Lender

Smart Lender is an AI-powered Loan Approval Prediction System developed using Machine Learning and Flask. The application helps banks and financial institutions evaluate loan applications quickly and accurately by analyzing applicant information such as education, employment status, annual income, loan amount, CIBIL score, and asset values.

Project Objective

The objective of this project is to automate the loan approval process using Machine Learning models, helping financial organizations reduce manual work, improve decision-making, and minimize the risk of loan defaults.
