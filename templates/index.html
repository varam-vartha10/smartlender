AI Powered Loan Approval Prediction

Smart Lender is a Machine Learning powered web application developed using Python, Flask and XGBoost. It helps banks and financial institutions quickly determine whether a loan application is likely to be Approved or Rejected based on applicant details.

⚡ Fast Prediction

Instantly predicts loan approval using Machine Learning.

🎯 High Accuracy

Uses the XGBoost algorithm with excellent prediction accuracy.

🔒 Secure

Applicant information is processed securely for prediction.

Machine Learning Models Used

Decision Tree

Simple and interpretable classification model.

Random Forest

Ensemble model providing better prediction performance.

K-Nearest Neighbors

Classifies applicants based on nearest neighbours.

XGBoost ⭐

Selected as the best performing model for deployment.
